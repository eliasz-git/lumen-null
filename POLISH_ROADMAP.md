# LUMEN NULL roadmap

## Done

- Raycast LiDAR: forward cone, persistent-then-fading round dots, random sizes,
  single white color (hunter red, exit cyan). Charge to trade range for recharge.
- Pause-and-tooltip tutorial (SPACE continue, ESC skip) with a real practice scan.
- Hidden exit gate that only appears when scanned, with a positional chime.
- Hunter: gaunt animated model whose parts are scannable, patrol / react /
  investigate / search / chase states, A* pathing around walls, hears sprinting,
  line-of-sight chase, positional footsteps, heartbeat, and alert sting.
- Level: floor-to-ceiling walls, scannable ceiling, pillars and cover.
- Audio: generated footsteps, ambient drone, alert sting.
- HUD: working vignette, charge/cooldown meter, win screen with run time and
  saved best time.
- Settings: sensitivity, volume, fullscreen. Mac launcher app runs from source.

## Next

- More levels behind the level select (the tutorial is level one).
- A second hunter type or a door/key objective.
- Scan-reactive environment (doors, lights, noisy objects as distractions).
- Gamepad support.
- Death replay / checkpoint.
