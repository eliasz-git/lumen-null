# LUMEN NULL polish roadmap

## Completed

- Unified lidar reveal treatment across platforms, walls, and moving platforms.
- Added charge percentage and pulse radius feedback to the HUD.
- Added central reticle and pulse screen flash.
- Added pulse charge/release audio feedback.
- Added hunter reaction delay, search behavior, red reaction light, and
  distance-based heartbeat pitch.
- Reworked title-screen wording and control presentation.
- Replaced the staircase route with a grounded stealth arena.
- Added contextual first-play guidance, an animated exit beacon, and a
  persistent comfort-settings menu.
- Reworked scan rendering into large circular point-cloud returns only.
- Tuned hunter speed, reaction timing, lethality, silhouette, and directional
  response audio.

## Current playable slice

- Grounded stealth arena replacing the old staircase/platforming route.
- Safe starting bay, central hunter space, cover routes, and an exit beacon.
- One hunter so the player can read and learn its response to a pulse.

## Next pass: authored experience

- Add a short safe opening that teaches movement and the first pulse.
- Add a deliberately staged first hunter reveal.
- Add a machinery or lift set piece that supports stealth rather than precision jumping.
- Add a final escape beat with a stronger goal treatment.
- Playtest route length, pulse timing, reveal duration, and enemy speed together.

## Presentation pass

- Replace the hunter capsule with a distinctive silhouette or animated mesh.
- Add footfalls, landings, cooldown-ready audio, and distant search audio.
- Add a stronger goal beacon and completion sound.
- Add a subtle ambient bed so silence feels intentional rather than unfinished.

## Comfort and accessibility

- Add mouse sensitivity and master-volume controls.
- Add fullscreen/windowed option.
- Preserve danger readability with visual cues in addition to audio.
- Verify text contrast and reticle visibility at different resolutions.

The guiding rule is that every presentation element should reinforce the core
tradeoff: information helps the player survive, but information creates danger.
